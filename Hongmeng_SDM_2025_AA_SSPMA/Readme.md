# Codes for Hongmeng-SDM forecast

# Papers:
    Ref1: J. Cang, Y. Gao and Y-Z. Ma, Sensitivity of the Hongmeng 21cm experiment to scattering dark matter, Astron.Astrophys. 714 (2026), A40 [arXiv: 2512.05056]
    Ref2: B. Li, et al., Investigating the nature of dark matter and early-universe black hole formation based on the Hongmeng measurement of the global 21-cm spectrum, SCIENTIA SINICA Physica, Mechanica & Astronomica (2026)
    Here Ref2 is a review partially based on Ref1

# Pipeline
0. Install 21cmFirstCLASS and get my PyLab repo
    21cmFirstCLASS url: https://github.com/Junsong-Cang/21cmFirstCLASS.git
    PyLab url: https://github.com/Junsong-Cang/PyLab.git
    For both repos (especially 21cmFirstCLASS), any commits around 2025/11 should be fine. I made some changes to the code to fix installation issues but I changed nothing related to physical implementations.
1. Build Fisher DataSet
    1.1 - First run Run_Fisher_DataSet.py with MPI and reload=1
    1.2 - Run it again but with reload=0 and no MPI
    1.3 - scp Fisher.h5 produced by Run_Fisher_DataSet.py to mac
2. Run cooling/heating samples
    2.1 - Run Run_Cooling_Samples.py with MPI & reload
    2.2 Run it again without MPI & reload
    2.3 scp cooling_rate.h5 to mac
3. Final Steps: 
    main_AA.ipynb runs everything needed by the AA paper
    main_SSPMA.ipynb runs everything needed by the SSPMA paper

# FileTree
DataSet
    - Run_Cooling_Samples.py: run Fisher dataset , stored in data/Fisher.h5
    - Run_Fisher_DataSet.py : run cooling/heatong rates, stored in data/cooling_rate.h5
Legacy
    - Different_DataSet
        Test whether using a different fiducial (EoS or OPT from EoS paper) or grid (BOX_LEN, HII_DIM) changes anything. Technically we should be using BOX_LEN>628 and HII_DIM >40 (see 21cmFirstCLASS tutorial), but this does not seem to change our results by more than ~30% so we should be safe.
        - Run_Cooling_Samples_LargeBox.py: 
            Run cooling/heatong rates for larger BOX_LEN and HII_DIM, supposed to save results in data/cooling_rate_LargeBox.h5 but we didn't finish it
        - Run_Fisher_DataSet_LargeBox.py:
            Run Fisher dataset for larger BOX_LEN and HII_DIM, stored in data/Fisher_LargeBox.h5. To see the impacts on our constraints, change Fisher.h5 to Fisher_LargeBox.h5 in ToolKit/Fisher_ToolKit.py
        - Run_Fisher_DataSet_OPT.py:
            A robustness test, run Fisher dataset for OPT (rather than EoS) fudicial setting in EoS paper. Supposed to save results to data/Fisher_OPT.h5 but we didn't finish it
    - Inference
        We were gonna go with inference but it didn't work out, no matter how we try, we still get that bump in sigma constraints around 1GeV due to local maximum. This folder keeps some of the tests and codes
        - Inference_Notes.md: logs of some tests we did
        - Inference_ToolKit.py: inference tools
    - Referee
        Reply to referee comments. We were lucky that we only need to do one revision so this is the only version
        - Referee.ipynb:
            Generate plots for referee reply
        - Run_Fisher_Linear_Samples.py:
            Generate samples with different masses, at each point sx is set to be their respective one-sigma limits. This is meant to test how Gaussian the likelihood is with respect to sx. Results are saved in /Volumes/X320/备份/SDM_HM_2512.05056/SDM_HM_Linear_cache/ but this does not take much cpu hours so if you accidentally delete them it should be fine as they will be easy to re-run

# Limits and caveats
- Ref1 and Ref2 results are different
    Ref2 was based on v1 version of Ref1 (see arXiv v1), which used 5 FG terms. The final v2 version of Ref1 used 7 FG terms which is why Ref1&Ref2 have different results.
- Simulation BOX_LEN
    We probably should have used larger BOX_LEN considering Fisher is fast anyway, but this does not change our results much (see comments above).
- Maximum z for astrophysical sources is limited due to mass variance interpolation table range
